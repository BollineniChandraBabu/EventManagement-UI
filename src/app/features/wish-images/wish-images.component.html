How images are chosen

When a wish email is sent, the first match is used:

  1. An image uploaded for that person and event type.
  2. An image uploaded for everyone for that event type.
  3. For festivals, the same two steps for the general Festival type.
  4. If nothing matches, an image is generated automatically. The email is always sent.

Event types are not case-sensitive. Use Birthday, Anniversary, Festival, a festival name such as Diwali, or any event type you created.
